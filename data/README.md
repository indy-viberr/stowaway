# Synthetic dataset notice

Every record in this directory — loads, invoices, PODs, scan images, carrier
names, MC numbers, and all "fraud" — is **synthetic**, generated by
`scripts/generate_dataset.py` (deterministic, seed 1979) for testing a fraud
*detection* pipeline. No real carriers, companies, or transactions are
represented. The planted anomalies are documented in `answer_key.json`.
